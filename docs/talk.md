Главная мысль: **агенты на арене за 27 попыток вырастили поиск навыков, который убирает около 60% ошибок классического поиска. Решение оказалось сборкой простых классических приёмов, а не одной умной моделью.**

## Цифры, которые надо помнить
- **BM25 против победителя:** private 0.608 → 0.856, public 0.537 → 0.8225. На `indirect` 0.156 → 0.624.
- **Поиск:** 27 решений из 30, 10 направлений, AUC 22.39 (`mean_quality` 0.746), плато после 19-го решения.
- **Финалисты на private:** r9-02 0.856, r10-01 0.853, r4-01 0.843, r6-01 0.840, r5-02 0.810.
- **Шум:** около 3 п.п. на 200 запросах и около 2.5 п.п. на 380.

## Вероятные вопросы
- **Почему не взять LLM для выбора навыка?** Это вариант AR-04а без LLM: решатель должен работать локально, на CPU, за секунды. С LLM была бы другая задача и другая цена.
- **Не подогнано ли под тест?** Private агенты не видели, его проверяли один раз, для пяти заранее зафиксированных финалистов. Доля убранных ошибок совпадает на всех трёх выборках.
- **Почему private выше public?** Он случайно оказался легче: BM25 там тоже выше (0.608 против 0.537).
- **Что дало больше всего?** Смысловая модель (+10 п.п. к лучшей лексике), затем гибрид (+4) и центрирование (+3).
- **Где решение ошибается?** На косвенных запросах без общих слов (0.62) и на навыках-близнецах, где описания почти совпадают.
- **Сходится ли арена к одному решению?** Не проверено: вторая кампания с другим стартом (B-5.3) не проводилась.
