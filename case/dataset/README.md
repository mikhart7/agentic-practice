# Данные

## Источник

### Каталог навыков (фиксирован, AR-04а)
189 навыков из официального реестра MCP (https://registry.modelcontextprotocol.io, снимок 2026-11-02). Каталог общий для всех split. По условию AR-04а он не меняется: эволюционирует только ранжировщик.

- [catalog_selection.toml](catalog_selection.toml) — ручной отбор: 24 кластера близких навыков (6–9 в каждом, источник hard negatives) и 13 одиночных навыков (`misc`). Каждый сервер закреплён версией.
- [build_catalog.py](build_catalog.py) — сборка: `snapshot` → `candidates` (подбор для ручного отбора) → `build`.
- `../assets/catalog.jsonl` — то, что видит решатель (`/assets/catalog.jsonl`): `id`, `name`, `description`. Описания короткие: 43–100 символов, медиана 90.
- [catalog_meta.jsonl](catalog_meta.jsonl) — кластер и источник `name@version`. Решателю не передаётся: кластеры — наша разметка, в реальном каталоге их нет.

Воспроизведение: `python case/dataset/build_catalog.py build` скачивает закреплённые версии и даёт побайтово тот же каталог.

Критерии отбора:
- одна понятная основная функция;
- английское описание без обрезки;
- внутри кластера навыки похожи, но различимы (например, Google Calendar, iCloud CalDAV и macOS Calendar.app);
- лексические ловушки: `cron-translator` в translation, `mindmeister` (mind maps) в maps-geo, словесная игра `words` при кластере weather.

`name` — это `title` из реестра, а без него последний сегмент имени: пространство имён `io.github.<user>` было бы шумом для поиска.

Лицензия: используются только метаданные реестра (имя и описание сервера), код серверов не используется.

### Запросы
Открытых данных «запрос → навык» для этого каталога нет, поэтому запросы синтетические. Их сгенерировала LLM по промпту [generation_prompt.md](generation_prompt.md). Как прошла генерация, что исправлялось и какие у неё ограничения — в [generation_report.md](generation_report.md).

Пул: 189 навыков × 2 намерения × 4 перефразы разных стилей = 1 512 запросов. Он хранится у оператора (`~/arena-private/pool/`), его sha256 записан в отчёте. [generate.py](generate.py) проверяет пул и детерминированно делит его на split.

```bash
python case/dataset/generate.py check                       # формат, id, стили, дубликаты
python case/dataset/generate.py split --seed 1              # train сюда, public/private в ~/arena-private
python case/dataset/check_bm25.py . ~/arena-private         # ориентир BM25 по split и стилям
python case/dataset/review_accept.py                         # лист ручной проверки разметки train
```

## Одно распределение
Все три split получены из одного пула, одним генератором, по одному промпту, одной процедурой деления. Отличаются только семейства, попавшие в раздел. Сдвига по навыкам нет: у каждого навыка одно семейство в train, другое — в public или private. Внутри кластера public и private чередуются, поэтому оба раздела покрывают все кластеры.

## Семейства
Семейство — одно намерение пользователя и 4 его перефразы (`family` = `<skill>#<n>` в `*.meta.jsonl`). Деление идёт целыми семействами. Перефраз запроса из train никогда не оказывается в public или private, поэтому кандидат, заучивший формулировки train, на held-out не выигрывает. Исследователь может использовать `family` из `train.meta.jsonl` для своей групповой кросс-валидации.

## Размеры и обоснование
| Split | Семейств | Запросов | Почему столько |
|---|---|---|---|
| train | 189 | 756 | по одному семейству на каждый навык: есть пример на каждый навык для обучения ранжировщика |
| public | 95 | 380 | ошибка acc@1 около 2.5 п.п. — отличимы кандидаты с разницей от ~5 п.п. |
| private | 94 | 376 | то же; финальное сравнение с baseline |

Обоснование:
- **Стоимость замера.** Решатель работает без LLM, прогон 380 запросов на CPU занимает секунды. Размер ограничен генерацией и требованием два семейства на навык, а не стоимостью.
- **Шум.** Стандартная ошибка acc@1 при p≈0.5 и n≈380 — √(0.25/380) ≈ 2.6 п.п. По BM25 public и private различаются на 7 п.п. (0.51 и 0.58), это укладывается в шум маленьких split.
- **Чего не хватает.** Чтобы уверенно различать кандидатов с разницей 2–3 п.п., нужно примерно втрое больше held-out запросов, то есть больше намерений на навык. Это возможное расширение до заморозки.

## Формат
UTF-8 JSONL, как требует оценщик арены (лишние поля он запрещает):
```json
{"id": "train-1a2b3c4d5e6f", "input": "merge these pdfs into one", "reference": "{\"primary\": \"pdfsamenvoegen\", \"acceptable\": [\"marqpdf\"]}"}
```
`reference` — JSON-строка: основной навык и допустимые альтернативы. Решателю она не передаётся. Метаданные лежат рядом в `<split>.meta.jsonl`: `family`, `style`, `cluster`, `intent`, `tags` (`hard` — навык из кластера близких).

Public и private (`public.jsonl`, `private.jsonl` и их `.meta.jsonl`) хранятся у оператора вне репозитория и вне доступа исследователя. В репозитории только `train.jsonl` и `train.meta.jsonl`.
