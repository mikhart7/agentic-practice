## Почему именно эти (а не top-5 по баллу)
- Разные механизмы по двум осям — **наличие лексики** и **число энкодеров** (+ способ слияния): ансамбль+лексика (r10-01), ансамбль+лексика с затвором (r9-02), ансамбль без лексики (r6-01), один энкодер+лексика (r4-01), один энкодер без лексики (r5-02). Ревьюер отметил: r8-01/r9-01/r6-01 почти совпадают (top-1 на 183–190 из 200), r4-01 заметно отличается (165/200 с r8-01), поэтому из близких пар взят один представитель.
- **Исключены как дубли/ниже по полезности:** r8-01 (public 0.8230 — тот же класс, что r10-01; r10-01 чуть выше, но замена r8-01 на r10-01 различима лишь в шуме, оба допустимы — берём r10-01 как наиболее обученный, r8-01 остаётся резервом), r9-01 (0.8057, граф+GBDT не дал выигрыша), r10-02 (≡ r6-01 по ответам, 200/200), r10-03 (≈ r4-01, 196/200), r2-02 (0.7426, отдельный dense без центрирования; r2-04 — сбой public), r1-03 (public 0.6792, лексика: нижняя граница, шансов попасть в выход N=2 нет), r3-02 (кросс-энкодер над лексикой, 0.673, ревью нет), r7-01 (почти дубль r4-01).

## Свидетельства, ограничения, риски
- **Шум:** на 200 запросах SE ≈ 3 п.п., на 380 ≈ 2.5 п.п.; различия r10-01 / r8-01 / r9-02 / r9-01 / r6-01 по public и curve **в шуме**; порядок внутри верхней группы не доказан.
- **r10-01:** `train_curve` не независим (обучение включало все семейства curve); перенос подтверждает только public (0.8267). Выбор `lr` держится на узком запасе CV (0.8310 vs 0.8253 при пороге 0.004). Build содержит время-зависимые ветки (`MODEL_BUDGET_S = 330`); измеренные сборки их не задействовали.
- **r9-02:** нет измерения на `train_curve` (прервано закрытием сессии оператора 2026-11-06; запись в train-сервисе не сбрасывается). Форма gate подобрана по тем же 556 записям fit (CV оптимистична: 0.8449 vs in-sample 0.8505); R9 при разработке нарушил правило «локально только чистый Python» (запись в `campaign.md`, пакеты R9 удалены 2026-11-06); анализ повлиял на дизайн, но параметры выбирает build. Для финала нужна именно эта пометка.
- **Общее:** fit-выборка содержит 139 из 189 навыков (r10-01 — все 189); public/private содержат навыки, уже виденные в train, с новыми формулировками — групповая CV их не измеряет, измеряет только public. Стиль indirect остаётся слабым (acc@1 ≈ 0.6) у всех. Ни одна версия не проверена на private.
- **Ресурсы:** токены решателя 0 у всех; solve 5–5.5 с на пример для ансамблей и ≈ 3–4 с для одиночных (замеры под нагрузкой, несопоставимы между собой), build 120–200 с из 600.
- **Аномалии/сбои оценщика:** отрицательное `judge_seconds` (r5-03-exp1, r7-01-curve, r9-02-exp1) — закрыты по решению оператора (`judge_seconds 0`, неполно, evidence); public r2-04 прерван закрытием сессии; все они записаны в `campaign.md` и не влияют на выбор финалистов.
