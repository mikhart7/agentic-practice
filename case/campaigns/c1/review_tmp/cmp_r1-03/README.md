# r1-03: r1-02 + косинус tf-idf по символьным триграммам

**Родитель:** r1-02. **Гипотеза.** Совпадения внутри слова (словоформы, составные слова, остатки опечаток) не ловятся токенами; триграммы с границами слова дадут дополнительный сигнал и разрешат ничьи при нулевом BM25.

**Механизм.** Для документа и запроса строится tf-idf вектор символьных триграмм (по словам без стоп-слов, `^слово$`), косинус; итог = BM25 / max(BM25 запроса) + 0.6 * cos. Вес 0.6 выбран по train вне train_curve (плато 0.3–1.0).

**Происхождение train-сведений.** Только выбор веса 0.6 (общий параметр). Таблиц запрос → ответ нет. build.py нет.

**Опровергающее наблюдение.** Нет прироста на casual/typo вне train_curve или регресс cmd/question.
