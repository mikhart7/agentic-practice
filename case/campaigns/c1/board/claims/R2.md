# Claim R2 (ветка r2-dense, направление 2: dense bi-encoder через build.py)

Дата: 2026-11-05. Квота: 5 мест (r2-01 ... r2-05).

## Гипотеза
BM25 проваливается на стиле `indirect` (acc@1 ~0.11): в запросе нет слов описания. Плотный bi-encoder из разрешённого списка
(`all-MiniLM-L6-v2`, `bge-small-en-v1.5`, `e5-small-v2`, `bge-base-en-v1.5`) сопоставляет смысл, поэтому
должен заметно поднять `indirect`, `question`, `casual`; на `cmd`/`typo` BM25 силён, там выигрыш не обязателен.

## Механизм
- `build.py` (однократно, в `/output`): кодирует каталог (name + description, с префиксом документа по модели) выбранной моделью,
  пишет матрицу эмбеддингов и список id.
- `solve.py`: читает только `/assets/prepared` (и модель из `/assets/models`), кодирует один запрос, косинус, топ-3.
- Инженерный вопрос: время solve. Одноразовый контейнер на пример, поэтому импорт torch + загрузка модели доминируют (~9 с с sentence_transformers).
  Вариант: прямой `transformers` (~4 с), либо forward энкодера на numpy (tokenizers + safetensors + numpy, без torch): запрос ~20 токенов,
  вычисление пренебрежимо; цель << 1 с на пример. Эквивалентность numpy-энкодера torch-эталону проверяется в build и пишется в `/output/report.json`.

## Область
Все 756 запросов train; отдельно срезы стилей (`indirect`, `typo`, `cmd`) и семейства вне `train_curve`.

## Ожидаемый эффект
`train_curve` score заметно выше baseline 0.488 (ожидание 0.65-0.75; bge-base >= bge-small > MiniLM; indirect acc@1 с 0.11 до >= 0.5).
Время solve: sentence_transformers ~9 с, numpy-путь ~1 с.

## Опровергающая проверка
- dense не лучше BM25 на `indirect` (acc@1 < 0.25) или общий score < 0.55: гипотеза о достаточности чистого dense опровергнута (нужен гибрид, направление 3).
- numpy-энкодер расходится с torch (косинус эмбеддингов < 0.999) или ранжирование на train отличается: ускорение опровергнуто.
- Префиксы/поля документа меняют acc@1 < 1 п.п. на train: это не рычаг.

## Происхождение train-сведений
Train в build не используется (только каталог и модель). Выбор модели/префикса/поля по train - настройка гиперпараметров, не обучение; ограничение для `train_curve` записывается в findings.

## Разведка вне журнала
Для офлайн-разведки (не замер кампании) в scratchpad поставлено окружение numpy/torch/sentence-transformers из публичного PyPI (сеть из контейнера исследователя доступна); прогоны только на train, public/private не использовались.
