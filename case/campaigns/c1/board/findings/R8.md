## r8-01
Гипотеза (аддитивность): лексика r1-03 поверх ансамбля r6-01 даёт заметный прирост (ансамбль +2.5, лексика +4 над одним dense). Механизм: dense как r6-01, поверх него лексика, методы `ens/wz/wz2/lr/lrm`, выбор по групповой CV в build (правило: лексика только при выигрыше >= 0.004).
CV на 556 запросах (центрирование и ансамбль в обоих случаях): ens 0.8337, wz 0.8383, wz2 0.8388, lr 0.8335, lrm 0.8344. То есть лексика даёт +0.5 п.п. (при шуме CV ~1.7 п.п.) против +2.6 п.п. над одиночным центрированным bge в r7-01 и +4 над сырым dense в r4-01: **большая часть выигрыша лексики уже забрана ансамблем**. Выбранный вес лексики 0.1 (z-единицы ансамбля) — лексика работает лишь как тай-брейкер, а не как равноправный признак. Парно в CV wz против ens: 24 лучше / 17 хуже.
CV по стилям (score, ens -> wz): question 0.778 -> 0.839, verbose 0.913 -> 0.958, typo 0.890 -> 0.909, cmd 0.905 -> 0.910, casual 0.875 -> 0.871, **indirect 0.699 -> 0.652**. Прирост лексики — на question/verbose/typo, потеря — на indirect (acc@1 0.662 -> 0.597): лексика почти нулевая на indirect (r1-03 acc@1 0.18) и переупорядочивает там верхушку в пользу «ловушечных» совпадений слов.
Curve: **0.800** (acc@1 0.765, nP@3 0.8817) против r6-01 0.79725: +0.275 п.п., парно 4 лучше / 3 хуже, кластерный bootstrap по семействам 95% CI [-0.6, +1.3] п.п. (неотличимо от нуля); против r4-01 0.7825: +1.75 п.п. (17/11, CI [-2.2, +6.4]). Ответы совпали с r6-01 на 127 из 200 (топ-1 различается на 10 примерах, остальное — 2-е/3-е места). По стилям (score r8-01 / r6-01 / r4-01): casual 0.812/0.807/0.755, cmd 0.904/0.910/0.912, indirect 0.630/0.630/0.570, question 0.778/0.778/0.822, typo 0.919/0.919/0.871, verbose 0.868/0.826/0.891. Время: solver_seconds 1317, median solve 5.5 с (r6-01 5.2 с): лексика добавляет ~0.3 с.

## r8-02 (родители r8-01, r6-01, r4-01): затворы лексики
Диагноз: в curve по ответам r4-01/r6-01 (чистый Python): когда золотой навык делит со запросом слово (160 из 200) acc@1 гибрида r4 0.881 против 0.831 у r6; когда общих слов нет (40 из 200, 25 из 50 в indirect) r4 0.25 против 0.475 у r6. Идеальная комбинация «r4 там, где есть слова, r6 там, где нет» дала бы acc@1 0.80 (+4 п.п.). Гипотеза: затвор лексики (только топ-K ансамбля `wzk`; сигмоид по пику z лексики `wzc`; оба `wzkc`; `lrg` — регрессия с затворными признаками) сохранит выигрыш на question/verbose и уберёт потерю на indirect.
CV в build (r8-02-exp1): ens 0.8337, wz 0.8383, wz2 0.8388, **wzk 0.8383** (= wz: выбранный K не ограничивает), **wzc 0.8386** (indirect 0.673 вместо 0.652, но question 0.814 вместо 0.839, verbose 0.930 вместо 0.958), wzkc 0.8322, lr 0.8335, lrm 0.8344, lrg 0.8338. Ни один затвор не лучше wz более чем на 0.003 → правило простоты выбрало `wz` w=0.1: **итоговый пакет r8-02 функционально равен r8-01** (fusion.json и mu_q совпадают байт в байт), curve не измерялась, чтобы не дублировать. Место потрачено на отрицательный результат: плата — по трейдоффу «лексика полезна там, где вопрос/длинный, вредна на indirect» нет затвора, который бы их развёл по признакам запроса и ансамбля (индирект-запросы с общим словом тоже ломаются: в curve у золотого есть общее слово в 25 из 50 indirect).

## Подтверждено
- Ансамбль r6-01 и гибрид пересекаются: лексика поверх ансамбля — +0.5 п.п. CV, +0.3 п.п. curve (в шуме); ансамбль уже решает typo (0.919) и частично verbose. Ориентир «оракул r6|r4» 0.815 acc@1 недостижим простым слиянием: выигрыши на question/verbose сопровождаются потерей на indirect.
- Лучший по curve из всех кампании: r8-01 0.800 (r6-01 0.79725, r7-01 0.7865, r4-01 0.7825), но разница с r6-01 не значима.
- Индирект остаётся узким местом: 0.63 (curve), acc@1 0.60; лексика и затворы его не двигают (золотой вне топ-3 у 15 из 50 при общей у r6-01).

## Опровергнуто
- Аддитивность «ансамбль +2.5 и лексика +4»: прирост лексики поверх ансамбля +0.5 п.п. CV / +0.3 п.п. curve.
- Затворы лексики (по рангу ансамбля, по уверенности лексики) и регрессия с затворами не лучше простого `wz` (CV 0.8322–0.8386 против 0.8383–0.8388); `lr/lrm` на ансамбле (0.8335/0.8344) не лучше ансамбля без лексики.
- Лексика полезна для indirect — нет: в CV indirect -4.7 п.п. при w=0.1.
