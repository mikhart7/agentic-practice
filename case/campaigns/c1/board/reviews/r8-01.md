## Вывод о допустимости: **допустим**

Совпадение `enc.py` (побайтово с r4-01/r6-01), `lex.py` (побайтово с r4-01) и `fit.jsonl` (sha256 `84e67e4e…`, как у r6-01) проверено `sha256sum`.

## Качество и риски
- train_curve **0.800** против r6-01 0.79725: +0.275 п.п., парно 4 лучше / 3 хуже, кластерный bootstrap по 50 семействам 95% [-0.6, +1.3] п.п. (пересчитано): неотличимо от нуля. Против r4-01 +1.75 п.п. (17/11), r7-01 +1.35 п.п. (11/5), интервалы включают 0. CV в build: ens 0.8337, wz 0.8383 (+0.5 п.п.; парно 24/17); по стилям лексика даёт +6 п.п. на question, +4 на verbose, но -4.7 п.п. на indirect.
- **Механизм** улучшения скромный: лексика с весом 0.1 — тай-брейкер поверх ансамбля. Большая часть выигрыша лексики уже забрана ансамблем (автор опроверг аддитивность). Альтернативное объяснение: эффект в шуме.
- **Риск переобучения:** низкий-умеренный. Обучаемые: три средних вектора, дискретные веса, один скаляр. Оптимизм CV ~0.5–1 п.п. (выбор ансамбля из ~50 конфигураций и метода из 4 по тем же 556). Fit содержит 139 из 189 навыков, в public/private навыки уже виденные (~73%); curve измеряет невиденные навыки, прямой замер на виденных — только public.
- **Роль в наборе / разнообразие.** По ответам curve (пересчитано): r8-01 и r6-01 совпадают в top-1 на 190 из 200, в упорядоченном top-3 на 127, в множестве top-3 на 148; r8-01 и r9-01 — top-1 190, упорядоченный top-3 105; r8-01 и r4-01 — top-1 165, r7-01 — 176. По acc@1 объединение r8-01+r9-01+r6-01 покрывает 156 примеров против 153 у лучшего из них (r6-01+r4-01+r7-01: 164 против 152). То есть r8-01, r6-01 и r9-01 по сути один механизм; для устойчивости финала брать не больше одного из них, второй слот — отличный по механизму (r4-01/r7-01). r8-01 — разумный «базовый» представитель семейства «ансамбль+лексика» (проще r9-*).
- Стоимость: build 195 с, solve медиана 5.5 с (2.1–11.3 с под нагрузкой слотов), память в пределах 2 ГБ.
