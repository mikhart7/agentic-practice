### Спорные фрагменты
- **`train_fit.jsonl` в пакете** — разрешён ADR-0004 («записи train, нужные для обучения, кандидат включает в свой пакет и указывает происхождение»), использован только build-ом.
- **4 навыка curve как «допустимые» в fit-записях** — см. п.4: слабая подсказка при обучении, не lookup; отмечено как ограничение независимости curve.
- **Тихий откат в build** (`except Exception` -> `wz w=0.5`): в зарегистрированном build не сработал (`report.json` без `fit_error`), но повторная сборка в другой среде могла бы дать другую конфигурацию; для private-отправки снимка важна идентичность `output_digest`.

## Качество и риски
- train_curve **0.7825** (acc@1 0.755, nP@3 0.847) против BM25 0.488, r1-03 0.6415, r2-04 0.7425. Различие с r6-01 (0.79725), r7-01 (0.7865), r5-02 (0.77275) — в шуме (n=200).
- **Риск переобучения:** низкий-умеренный. Параметры: 9 весов + нормировки на 556 запросов; выбор метода из 4 по CV (небольшая оптимистичность CV признана автором). Устойчивость: CV и curve согласованы.
- **Виденные/невиденные навыки.** Fit содержит 139 из 189 навыков; в public/private навыки уже виденные (около 73% по первичным навыкам, по постановке). Веса навык-независимые, а CV по семействам имитирует невиденные навыки, поэтому занижать перенос нет причин, но и прямой замер на «виденных навыках» (кроме записи public из журнала) отсутствует. Если для финала обучать на всех 756 записях, curve перестаёт быть независимым; это другая версия (новое ревью).
- Стоимость: build 122 с, solve порядка 1.7–4.6 с (зависит от нагрузки), два прохода энкодера на запрос.

## Роль в финальном наборе
Базовый гибрид «лексика + dense с обученным слиянием»: разнообразие механизма относительно чистого dense (r6-01) — высокое по ошибкам (top-1 совпадает с r6-01 в 81% случаев), но r7-01 — прямой потомок этого же кода (top-1 совпадает на 87%, top-3 идентичны в 66 из 200). Для набора выбирать **либо r4-01, либо r7-01**: r7-01 лучше по CV (0.8241 против 0.8147) без добавления обучаемых матриц; r4-01 — страховка с меньшим числом решений в build (122 против 267 с). Комбинация r4-01 (лексика) + r6-01 (ансамбль) даст разнообразие.
