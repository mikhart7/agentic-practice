- **Тихий откат** на `wz w=0.5` без центрирования при ошибке обучения (`fit_error`) — в зарегистрированном build не сработал.

## Качество и риски
- train_curve **0.7865** (acc@1 0.750, nP@3 0.872); по стилям: cmd 0.915, indirect 0.588, question 0.800, casual 0.783, typo 0.886, verbose 0.850. Лучшая CV среди гибридов (0.8241). Различие с r4-01, r5-02 и r6-01 по curve в шуме (n=200).
- **Риск переобучения:** низкий. Обучаемые параметры: `mu_q` (2×768), один вес `w`, булевы выборы по CV; выбор из 4 вариантов с заранее заданным правилом. Навык-специфичной информации нет.
- **Виденные навыки.** Fit содержит 139 из 189 навыков; в public/private навыки уже виденные (около 73%). Эффект центрирования измерен на невиденных навыках (curve), перенос на виденные не проверен; параметры навык-независимы, но `mu_q` отражает распределение запросов 139 навыков.
- **Операционный риск:** запись замера в журнале не завершена (аномалия `judge_seconds`); исправление инструмента/журнала вне полномочий исследователя.
- Стоимость: build 267 с (лишние ~117 с на кросс-энкодер, не вошедший в итог), solve ~1.5–4.5 с.

## Роль в финальном наборе
Близкий потомок r4-01 (центрирование + w=0.1 вместо `lr`), эквивалентен по curve и чуть лучше по CV; **разнообразие относительно r4-01 небольшое** (top-1 совпадает в 87%, top-3 идентичны в 66 из 200), поэтому в набор имеет смысл брать **один из пары r4-01/r7-01**; r7-01 предпочтительнее при выборе по CV и по простоте обучаемой части, r4-01 — по меньшему времени build и более зрелому набору свидетельств (в журнале завершённый замер curve). Относительно r6-01 даёт другой механизм (лексика + один dense), поэтому в паре с r6-01 полезен для устойчивости.
