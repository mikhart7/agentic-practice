# Baseline: BM25 по описаниям

Стартовый кандидат эволюции и точка сравнения на private (baseline из карточки AR-04).

- Документ навыка — `name + description` из `/assets/catalog.jsonl`. Токены — `[a-z0-9]+` в нижнем регистре, без стемминга и стоп-слов.
- BM25 Okapi, `k1 = 1.5`, `b = 0.75`, idf `log(1 + (N − df + 0.5) / (df + 0.5))`. При равенстве score порядок задаёт каталог, поэтому ответ детерминирован.
- Ответ — топ-3 id.
- Только стандартная библиотека Python: решение не требует зависимостей в runner-образе.

Почему стартовый: простейший разумный поиск по исходным описаниям. Его слабости (нет синонимов, нет перефраз, короткие описания ≤100 символов) — то, что должна исправлять эволюция.
