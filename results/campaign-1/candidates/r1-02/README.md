# r1-02: r1-01 + исправление опечаток по словарю каталога

**Родитель:** r1-01. **Гипотеза.** В стиле typo слова с опечатками («serch», «campain», «screnshot») не входят в словарь каталога и выпадают из запроса; приближение к ближайшему слову каталога (одна правка Дамерау-Левенштейна) вернёт сигнал.

**Механизм.** Слово запроса (после стоп-слов), чья основа отсутствует в словаре каталога и чья длина >= 6, заменяется ближайшим словом каталога (одна правка; при нескольких — с той же первой буквой и более частое). Вес замены 0.7. Для коротких слов (< 6) соседей слишком много — ложные исправления («later» -> «layer»), порог выбран по train вне train_curve. Знания — только словарь каталога.

**Происхождение train-сведений.** Train использован только для выбора порога длины (6) и веса (0.7): общие параметры. Таблиц запрос → ответ нет. build.py нет.

**Опровергающее наблюдение.** Рост typo не подтверждается на других семействах или падают другие стили.
