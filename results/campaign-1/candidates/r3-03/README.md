# r3-03: лексика r1-03 -> топ-N -> ms-marco-MiniLM-L6-v2 -> смесь z-оценок с весом, подобранным в build

**Родители:** r3-02 (чистая замена порядка топ-20 той же моделью, train_curve 0.6727), r3-01 (bge-reranker-base, 0.6545), r1-03 (первая стадия, 0.6415).

**Гипотеза.** Полная замена порядка кросс-энкодером теряет информацию первой стадии (r3-01/02: +0.013/+0.031 к лексике при потолке recall@20 ~0.87, в топ-20 acc@1 всего 0.75). Смесь нормированных оценок `w*z(лексика) + (1-w)*z(кросс-энкодер)` внутри топ-N, с N и w подобранными на train вне train_curve, должна дать больше, чем любая из стадий отдельно. Если выбранное w близко к 0 или 1, соответствующая стадия достаточна.

**Механизм.** `build.py` (один раз, в runner): для 300 запросов из `fit.jsonl` берёт топ-20 лексики r1-03, оценивает пары (запрос, "name. description") моделью ms-marco-MiniLM-L6-v2, перебирает сетку N in {3,5,8,10,15,20} x w in [0,1] шаг 0.05, выбирает максимум метрики 0.7*acc@1 + 0.3*nP@3 со сглаживанием по соседним w; пишет `params.json` (N, w) и `report.json` (вся сетка, время, оценки только-лексики и только-кросс-энкодера на тех же запросах). Сбор оценок ограничен 420 с, при менее 100 запросов build падает. `solve.py` читает `/assets/prepared/params.json`, ранжирует лексикой, оценивает топ-N кросс-энкодером, смешивает и отдаёт топ-3. Модели нет в `prepared`, только два числа.

**Изменения относительно r3-02.** Появились `build.py`, `rerank.py`, `fit.jsonl`; смешивание вместо замены; N и w подобраны, а не заданы.

**Происхождение train-сведений.** `fit.jsonl`: 300 записей из `case/dataset/train.jsonl` (случайная выборка seed 7 после исключения всех 200 запросов `train_curve`; общих с curve семейств нет), поля `input` и `relevant` (primary + acceptable). Назначение: подбор двух скаляров (N, w) в build. Таблицы запрос -> ответ в `solve` нет, `solve` файл не читает; в `prepared` попадают два числа. Разрешающий пункт: ADR-0004, build: «обучение на train: калибровка». Оценка на train_curve остаётся независимой от подбора N и w (но не от выбора модели и самой схемы, см. findings).

**Опровергающее наблюдение.** Score на train_curve не выше 0.6727 (r3-02) - смешивание не помогло; выбранное w >= 0.9 или <= 0.1 - одна из стадий достаточна; fit-оценка смеси не выше max(fit-оценка только-лексики, только-кросс-энкодера) - нет комплементарности.
