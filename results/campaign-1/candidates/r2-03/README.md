# r2-03: bge-small-en-v1.5 + query-инструкция BGE (тот же код, что r2-02)

Родитель: r2-02 (bge-base, 0.7395 на train_curve, solve медиана 1.57 с).

## Гипотеза
Из 4 разрешённых bi-encoder именно размер модели определяет время solve в одноразовом контейнере: bge-small (133 МБ весов, 384-мерные векторы) читается и считается примерно в 3 раза быстрее bge-base (438 МБ). Если качество на train_curve в пределах шума (~3 п.п.) от r2-02, small выигрывает по правилу «при равном качестве — меньше времени». Опровержение: score ниже r2-02 более чем на 3 п.п.

## Механизм
Без изменений кода относительно r2-02 (build: эмбеддинги каталога sentence-transformers + проверка numpy-энкодера; solve: numpy-энкодер запроса, косинус, топ-3). Меняется только `params.json: model`.

## Происхождение train-сведений
Нет: train не используется.
