# r3-01: лексика r1-03 -> топ-20 -> кросс-энкодер bge-reranker-base

**Родитель:** r1-03 (лексика, train_curve 0.6415).

**Гипотеза.** Верный навык чаще попадает в топ-N лексики, чем на первое место (curve: recall@1 0.61, @3 0.735, @20 0.835). Кросс-энкодер, оценивающий пары (запрос, "name. description"), расставляет кандидатов точнее BM25 и поднимает acc@1 к потолку recall@20.

**Механизм.** `lexical.py` - логика r1-03 без изменений (проверено: топ-3 совпадает с ответами r1-03 на всех 200 примерах curve). `solve.py` берёт топ-20 кандидатов, оценивает пары моделью `/assets/models/bge-reranker-base` (transformers, 2 потока, max_length 256), заменяет порядок топ-20 порядком оценок (ничья - по рангу первой стадии), отдаёт топ-3. Без build, без предвычислений. Сбой модели не маскируется запасным ответом.

**Изменения относительно r1-03.** Вторая стадия; `solve.py` разбит на `lexical.py` и `solve.py`.

**Происхождение train-сведений.** Нет: train не используется. Анализ recall@N на train - только для выбора N.

**Опровергающее наблюдение.** score на train_curve не выше 0.6415 или падение cmd ниже 0.85.
