# scripts

CLI итогового решения — кандидата-победителя r9-02 из журнала кампании c1.

| Файл | Что это |
|---|---|
| `select_skill.py` | CLI: каталог + запрос → топ-k навыков (JSON). Повторяет `solve.py` кандидата; эмбеддинги каталога считает сам и кэширует, вместо `/assets/prepared` |
| `enc.py`, `lex.py`, `hyb.py` | файлы кандидата без изменений, как в снимке [results/campaign-1/candidates/r9-02](../../results/campaign-1/candidates/r9-02/README.md): numpy-энкодер BERT, лексика (BM25 + триграммы), слияние |
| `params/` | выход build кандидата на арене (публикация `9884760b…`): модели и веса ансамбля (`config.json`), центрирующие векторы запросов (`mu_q.npz`), метод слияния `gate` и его параметры (`fusion.json`) |
| `fetch_models.py` | загрузка трёх энкодеров по тем же ревизиям Hugging Face, что в [case/assets/models.toml](../../case/assets/models.toml) |
| `requirements.txt` | закреплённые зависимости, версии взяты из `uv.lock` репозитория; torch не нужен |

**Сверка с ареной.**
- Эмбеддинги каталога совпадают с результатом build на арене: минимальный косинус 0.9999998 по всем трём моделям.
- На 54 запросах `train_curve`, которые арена успела оценить для r9-02, ответы совпадают с ответами кандидата 54 из 54.
- На всех 200 запросах `train_curve` CLI набирает 0.8315 по замороженной метрике кейса.
